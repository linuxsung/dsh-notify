# 에셋·상표 라이선스 정책 — BYO(Bring Your Own) 방식

> 상태: active · 최종 갱신: 2026-10-23 · git: main @ 8129b54 · 상위: [README.md](../README.md)

- 목적: 오픈소스 재배포 시 폰트·로고·사운드 라이선스 분쟁을 원천 차단한다.
- 원칙: **패키지는 에셋을 배포하지 않는다.** 사용자가 직접 주입한 에셋만 로컬에서 사용한다.
- 적용 대상: `@nolit/dsh-notify-web`(웹 플러그인), 윈도우 오프피크 위젯(포터블 패키지).
- 코드 라이선스: MIT ([LICENSE](../LICENSE)).

## 1. 기본 원칙

1. **기본값은 라이선스가 명확한 시스템 자산**을 쓴다.
2. ** Digital-7, DeepSeek 로고, `ding.wav`는 저장소/배포물에서 제외**한다. 로컬 개발 편의를 위해 남아 있더라도 공개 아티팩트에는 포함하지 않는다.
3. 사용자 주입 에셋은 앱이 **감지하면 우선 적용**하고, 없으면 기본값으로 조용히 폴백한다.
4. 사용자 주입 에셋의 라이선스/재배포 권리는 **사용자 책임**이며, 프로젝트는 이를 배포하지 않는다.
5. 기본 아이콘/코드 외에 제3자 에셋을 포함할 경우 `THIRD-PARTY-NOTICES.md`에 출처/라이선스를 기록한다.

## 2. 폰트

### 2.1 기본값

- 타이머: `Consolas, "Cascadia Mono", "Segoe UI", monospace` 순서의 시스템 폰트.
- 일반 UI: `"Segoe UI", system-ui, sans-serif`.
- 별도 TTF/OTF를 패키지에 넣지 않는다. OS 기본 폰트로 렌더링한다.

### 2.2 사용자 주입(BYO)

- 경로: `<widget-data>\fonts\digital-7.ttf` (권장) 또는 `fonts\*.ttf`.
- 앱은 시작 시 `fonts\digital-7.ttf` 존재 여부를 확인하고, 로드에 성공하면 타이머 폰트로 우선 사용한다.
- 파일이 없거나 로드에 실패하면 시스템 폰트로 폴백한다. 오류를 띄우지 않는다.
- README에는 폰트 배포 페이지 링크만 안내한다. 패키지에 폰트 파일을 포함하지 않는다.
  - Digital-7 제작사: <https://www.styleseven.com/>
- 사용자는 다운로드한 폰트의 라이선스를 직접 확인해야 한다. Digital-7은 제작사 EULA상 가정용/프리웨어 조건이므로, 상업적 사용자는 별도 라이선스를 구매해야 한다.

### 2.3 웹 플러그인

- 웹 플러그인은 폰트를 번들하지 않으며, DSH/브라우저의 시스템 폰트를 그대로 쓴다.
- 웹 알림에는 커스텀 폰트를 적용하지 않는다.

## 3. 아이콘·상표

### 3.1 기본 아이콘

- 웹 플러그인: `plugin/icon.svg` — 자체 제작한 중립 알람시계 SVG(MIT).
- 윈도우 위젯: 동일 계열의 중립 시계/타이머 `.ico`. 기본 배포물에 DeepSeek 로고를 넣지 않는다.
- 트레이/창 아이콘은 중립 아이콘을 기본으로 하고, 사용자가 교체할 수 있다.

### 3.2 DeepSeek 로고

- DeepSeek 공식 로고/워드마크/브랜드 자산은 **배포 패키지에서 완전히 제외**한다.
- 저장소에 남아 있는 로컬 개발용 로고 파일은 공개 아티팩트 빌드에서 제외한다.
- 사용자가 로컬에서 직접 넣는 경우에도 상표 사용 권한은 사용자 책임이다.

### 3.3 사용자 커스텀 아이콘

- 경로: `<widget-data>\icons\custom.ico` (트레이/앱 아이콘), 선택적으로 `icons\custom.png`.
- 앱은 `custom.ico`가 있으면 우선 사용하고, 없으면 중립 기본 아이콘을 쓴다.
- 잘못된 ICO/크기 불일치는 무시하고 기본 아이콘으로 폴백한다.
- 웹 플러그인은 알림 아이콘을 지정하지 않는다(브라우저 기본 표시). 커스텀 아이콘 주입은 위젯 전용이다.

## 4. 사운드

### 4.1 웹 플러그인

- `ding.wav`를 번들하지 않는다.
- Web Audio API로 짧은 2음 차임을 합성한다(예: 880Hz/1175Hz, 120ms).
- 사용자 제스처 전에는 `AudioContext`가 잠겨 있을 수 있으며, 패널의 “소리 켜기”로 활성화한다.

### 4.2 윈도우 위젯

- `notify/ding.wav`를 배포물에서 제거한다.
- 시스템 기본 알림음(`[System.Media.SystemSounds]::Asterisk` 등) 또는 무음 정책을 사용한다.
- 별도 오디오 파일을 패키지에 넣지 않는다.

## 6. 패키징 검사

공개 아티팩트(`npm pack`, 위젯 zip)에 다음이 없어야 한다.

- [ ] `digital-7.ttf`, 기타 Digital-7 폰트 파일
- [ ] `deepseek-logo*.png`, `deepseek-*.ico` 등 DeepSeek 브랜드 자산
- [ ] `ding.wav`, 기타 출처 불명 오디오 파일
- [ ] `DSH-Notify.exe`, `start.vbs` (SAC/VBScript 문제)
- [ ] 사용자 `config.json`, 로그, 캐시, 개인 경로

검사 예:

```powershell
# 저장소에서 금지 에셋이 있는지 확인
Get-ChildItem -Recurse -File |
  Where-Object { $_.Name -match 'digital-7|deepseek-logo|ding\.wav|DSH-Notify\.exe|start\.vbs' } |
  Select-Object FullName

# npm 패키지 내용 확인
npm pack --dry-run --json
```

> 로컬 개발용 `ui/assets`에 기존 에셋이 남아 있을 수 있다. 이는 공개 빌드 입력에서 제외하며, 위젯 패키징 단계에서 정리한다.

## 7. 사용자 안내(README용)

### 폰트

1. <https://www.styleseven.com/>에서 Digital-7 폰트를 내려받는다.
2. 앱 데이터 폴더에 `fonts\digital-7.ttf`로 저장한다.
3. 앱을 재시작하면 타이머에 적용된다. 파일이 없으면 Consolas/Segoe UI로 표시된다.
4. 폰트 라이선스는 사용자가 직접 확인한다.

### 아이콘

1. 사용할 `.ico` 파일을 준비한다.
2. 앱 데이터 폴더에 `icons\custom.ico`로 저장한다.
3. 앱을 재시작하면 트레이/창 아이콘에 적용된다.
4. 없으면 중립 기본 아이콘이 사용된다.

### 사운드

- 웹 플러그인: 패널에서 “소리 켜기” 후 Web Audio 차임 사용.
- 윈도우 위젯: 시스템 기본 알림음 사용. 별도 파일 없음.
